## Brand & Style

This design system is engineered for mission-critical emergency dispatch and real-time vehicle telematics. In life-or-death scenarios where split seconds dictate outcomes, visual friction must be zero. The interface prioritizes cognitive clarity, situational awareness, and immediate legibility under stress and varying ambient light conditions found in tactical command centers.

The design movement combines **Mission-Control Brutalism** with **High-Density Data Minimalism**:
- **Utilitarian & Tactical:** Functional borders, structural delineation, and monospaced data alignment eliminate ambiguity.
- **Visual Urgency Hierarchy:** Surfaces remain deep, quiet, and non-distracting (#0B0F19), allowing functional emergency accents (cyan, amber, red, emerald) to signal status, priority, and routing directives instantly.
- **Zero-Fatigue Contrast:** Built around strict WCAG AAA guidelines to safeguard operator focus over extended 12-hour shifts.

## Colors

The color palette is rooted in an ultra-deep charcoal slate baseline, punctuated by high-potency functional accents for telemetry, situational alerts, and geospatial routing paths.

### Palette Architecture
- **Command Backgrounds**: 
  - Canvas Deep: `#0B0F19` (lowest base tone, map baseline)
  - Surface Substrate: `#111827` (card panels, drawer bays)
  - Surface Elevated: `#1E293B` (popovers, flyouts, contextual menus)
- **Primary Telemetry Accents**:
  - Primary Electric Cyan: `#38BDF8` (active selected vehicle, live target ETA, key focal action)
  - Secondary Tactical Blue: `#0284C7` (standard emergency path, structural controls, secondary interactive nodes)
- **Tactical Status Semantics**:
  - Hazard / Priority 1 Alert: `#EF4444` (road blockage, critical incident, SOS dispatch)
  - Amber Caution / En Route: `#F59E0B` (congestion, delayed response, high traffic bottleneck)
  - Emerald Operational: `#10B981` (unit clear, green corridor engaged, route cleared)
  - Route Alternative Vector: `#8B5CF6` (secondary routing option, staging corridor)
- **Data & Text Contrast**:
  - Primary Readout: `#F8FAFC` (100% white-slate for mission numbers, ETAs, titles)
  - Secondary Telemetry: `#94A3B8` (unit coordinates, sub-labels, metadata)
  - Grid & Boundary Dividers: `#334155` (crisp, precise, 1px separation lines)

## Typography

Typography is split strictly into two roles:
1. **Inter** handles high-throughput navigational copy, system alerts, incident details, and structural controls with tabular figures enabled (`tnum`).
2. **JetBrains Mono** governs tactical readouts, dynamic countdown timers, unit identifiers (e.g., `MEDIC-42`, `ENG-101`), GPS coordinates, and vehicle velocity vectors.

### Execution Rules
- Monospace figures must always be used for changing numbers to eliminate horizontal layout jitter during real-time updates.
- All badge labels and status indicators use uppercase `label-code` with micro tracking (`0.05em`) for legibility from arm's length or across console banks.

## Layout & Spacing

The layout operates on a **Fixed-Fluid Hybrid Control Shell**:
- **Map Viewport**: Continuous fluid canvas spanning the underlying base view.
- **Docked HUD Panels**: Fixed-width sidebars (Left: Incident Triage Queue at 380px; Right: Unit Telemetry & Turn-by-Turn Matrix at 420px).
- **Responsive Adaptations**:
  - **Desktop (>= 1280px)**: Persistent multi-pane layout; HUD sidebars pin to boundaries over the map canvas. Gutter spacing maintains 16px (`1rem`) to support high density.
  - **Tablet (768px - 1279px)**: Split-screen mode with collapsible drawers. Active incident map retains primary viewport.
  - **Mobile (< 768px)**: Bottom-sheet operational mode. The map takes 60% viewport height with an expandable gesture card anchoring vehicle speed, next maneuver, and critical action buttons.

## Elevation & Depth

This system intentionally eliminates traditional blurred drop shadows to avoid muddying dark interfaces in dim lighting. Visual layering is achieved purely via **crisp structural borders**, **tonal value shifts**, and **tactical status glows**:

- **Ground (Map Canvas)**: `#0B0F19`. Zero elevation.
- **Layer 1 (Telemetry Panels & Docked Bins)**: `#111827` framed by a 1px solid border of `#1E293B`.
- **Layer 2 (Selected Cards & Active Incidents)**: `#1E293B` with high-contrast active borders:
  - Active: 1px border of `#38BDF8`.
  - Critical Priority: 1px border of `#EF4444`.
- **Layer 3 (Overlays, Modal Directives, Diagnostics)**: `#0F172A` with a 1px border of `#334155` and a tight, localized 2px rim glow tinted with the primary accent: `0 0 0 1px #38BDF8, 0 8px 24px rgba(2, 132, 199, 0.25)`.

## Shapes

The interface embraces a precise, utilitarian shape language (`roundedness: 1`):
- Base interactive targets (buttons, inputs, telemetry cards) use `0.25rem` (4px) corner radii.
- Outer panel boundaries, modal dialogs, and floating sheets use `rounded-lg` (8px).
- Badges and micro-status indicators retain strict, near-rectangular form with subtle 2px to 4px corners to communicate industrial rigidity rather than consumer softness.
- Circular geometry is reserved exclusively for map pin avatars, radar pulses, and orientation heading compasses.

## Components

### Buttons & Dispatch Actions
- **Primary Mission Button (Dispatch / Reroute)**: Solid `#0284C7` background, `#F8FAFC` text, 4px corner radius, bold Inter typography. Active/focus state emits a `#38BDF8` 1px outer ring.
- **Emergency Overrule Button**: High-potency `#EF4444` background with white text, triggering visual confirmation hold states.
- **Secondary Utility Buttons**: `#1E293B` surface, `#94A3B8` text, `#334155` 1px border. Hover shifts text to `#F8FAFC` and border to `#38BDF8`.
- **Minimum Tap Target**: Desktop `36px` height for density; touch/field consoles `48px` minimum.

### Telemetry Badges & Incident Chips
- Solid dark substrate (`#0B0F19`) framed by a 1px solid semantic border with matching text.
  - Priority 1 (Hazard): `#EF4444` text and border with a pulsing 6px circle indicator.
  - En Route / Delayed: `#F59E0B` text and border.
  - Green Light Corridor Active: `#10B981` text and border.
  - Alternate Path: `#8B5CF6` text and border.
- Text is set in uppercase `label-code` (JetBrains Mono).

### Data Tables & Incident Lists
- Segmented lines with 1px `#1E293B` borders; alternating row banding is omitted in favor of hover highlighting with `#1E293B`.
- Key metrics (ETA, Delta, Speed, Unit ID) are pinned to right-aligned columns in `metric-md` monospace.

### Inputs & Route Parameter Controls
- Background `#0B0F19`, 1px border `#334155`, text `#F8FAFC`.
- Focus state instantly replaces border with 1px `#38BDF8` with zero transition delay for snappy operational feedback.
- Stepper controls and coordinate inputs leverage JetBrains Mono with tabular digit spacing.

### Mission Telemetry Cards
- Structured modular containers featuring a fixed 28px header row showing Unit Call Sign, Status Badge, and current Speed.
- Card divider: 1px `#1E293B`. Body houses real-time route path graph and turn telemetry.
- Selected vehicle card shifts border to `#38BDF8` with a subtle 4px left-hand border indicator strip.
